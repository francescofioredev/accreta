# Source documents

**These are stand-ins, not the real reports.** They are short paraphrases written for this
demo so that the repository stays small and carries no third-party text.

Every figure in them is approximately right and attributed to the body that published it, so
citations point somewhere meaningful. Do not quote them as sources; go to the real documents.

The point of the demo is the *mechanics* — provenance, the link graph, drift detection — not
the climate science. A knowledge base whose sources are fabricated wholesale would be a
dishonest demonstration of a tool whose entire purpose is provenance, which is why this file
exists.
