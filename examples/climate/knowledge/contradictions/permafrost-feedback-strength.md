# Disagreement on permafrost feedback strength

Two sources in this knowledge base give values differing by a factor of three.

| Source | Value | Scope |
|---|---|---|
| [[findings/permafrost-feedback-gradual]] | ~0.09 W m-2 per degree | excludes abrupt thaw[^a] |
| [[findings/permafrost-feedback-abrupt]] | ~0.27 W m-2 per degree | includes abrupt thaw[^b] |

Both sources state their own scope, and the scopes differ: one excludes abrupt thaw
explicitly,[^a] and the other includes it.[^b] The second source states directly that the
difference is not primarily a measurement disagreement but a difference in which processes
are modelled.[^why]

**No reconciliation is attempted here.** A single number could be produced by choosing a
source, averaging, or preferring the more recent — and each of those would present a
scope difference as a settled quantity. The disagreement is the current state of the
evidence, and it is the thing a reader needs to know.

This page exists because [[findings/carbon-budget]] depends on the permafrost response, so
anyone using that budget needs to know the input is contested.
