# Experiments

Measurements that were designed during the review but not run.

Each card states a question, a hypothesis phrased so that it can fail, the method in enough
detail to execute, the metric and why that metric rather than another, and — the part that
makes it an experiment rather than a plan — the result that would refute the hypothesis.

A card here is not a commitment to run it. It exists so that a finding which needs a number
can name the number it needs, instead of being argued from intuition and shipped as though
it had been measured.
